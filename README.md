# Official Portfolio

My personal portfolio website, built to showcase who I am, what I've worked on, and how to get in touch. Live at **[dhanalakshmi-d.vercel.app](https://dhanalakshmi-d.vercel.app/)**.

## ✨ Features

- **About** – A quick introduction and background
- **Skills** – Technologies and tools I work with
- **Projects** – A showcase of selected work
- **Resume** – Downloadable/viewable resume
- **Contact** – Ways to reach out and connect

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

Clone the repository and open it locally:

```bash
git clone https://github.com/Dhanalakshmi-D04/official_portfolio.git
cd official_portfolio
```

Then simply open `index.html` in your browser — no build step required.

## 📦 Deployment

This project is deployed on [Vercel](https://vercel.com/). Any push to the main branch automatically triggers a new deployment.
